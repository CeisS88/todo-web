## To-Do List web
A simple and responsive To-Do List web application featuring a glassmorphism UI and automatic data persistence via `localStorage`.

## Features

- **Task Management**: Add, complete, and delete daily tasks.
- **Data Persistence**: Tasks are saved locally in the browser (`localStorage`).
- **Input Sanitization**: Basic XSS protection using standard DOM methods (`createTextNode`).
- **Responsive Layout**: Designed to adapt across mobile and desktop screens.

## Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
